# Découvrez la programmation orientée objet avec Python

Course-long project ("fil rouge") of the eponymous [OpenClassrooms](https://openclassrooms.com/) course on object-oriented programming with Python.

## About The Project

From the original README (in French): the project simulates a virtual world populated by 100,000 people and looks into two questions: from which population density people become less pleasant than average, and from which age people earn more than average. When the program runs, a first window shows a chart about population density, then a second one about income.

Original text:

> Projet servant de fil rouge au cours du même nom disponible sur OpenClassrooms.
>
> Nous simulons ici un monde virtuel peuplé de 100 000 personnes. Nous cherchons à connaître :
> - à partir de quelle densité de population les personnes sont moins agréables que la moyenne,
> - à partir de quel âge les personnes gagnent plus d'argent que la moyenne.
>
> Lorsque le programme se lance, une première fenêtre affiche un graphique concernant la densité de population puis une seconde concernant le revenu.

The simulated population is generated by `download_agents.py` into `agents-100k.json`, and the analysis lives in `model.py` / `model.ipynb`.
